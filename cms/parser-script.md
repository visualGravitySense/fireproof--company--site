Отлично, первый этап пройден — список сайтов у нас в руках!

Теперь задача усложняется: чтобы собрать email-адреса, нужно зайти на каждый сайт из вашего CSV-файла. Это уже нельзя сделать простым скриптом в консоли браузера (из-за правил безопасности CORS), здесь понадобится **Python**.

### Готовый скрипт: `collect_emails.py`

Скрипт находится в папке `cms/` и делает следующее:
- Читает `neti_kinnisvara_links.csv`
- Заходит на каждый сайт, ищет email в HTML
- Если на главной не найдено — проверяет страницы `/kontakt`, `/contact`, `/about` и др.
- Сохраняет результат в `neti_with_emails.csv`

### Запуск

```bash
cd cms
pip install -r requirements.txt
python collect_emails.py
```

### Нюансы

* **Скрытая почта:** Сайты с обфускацией (`info [at] domain.ee`) или JS-подстановкой — скрипт их не увидит.
* **Блокировки:** Встроена пауза 2 сек между запросами. При необходимости измените `DELAY_SEC` в скрипте.
* **Страница контактов:** Скрипт автоматически проверяет `/kontakt`, `/contact`, `/kontaktid`, `/about`, `/meist`.
